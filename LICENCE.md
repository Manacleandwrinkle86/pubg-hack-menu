## 🧩 About

**PUBG Companion** is a curated list of PUBG open-source tools:

- **Overlays** — on-screen helpers, layout notes, player tracker, zone timer
- **Quality-of-Life Helpers** — loot catalog, weapon stats, overlay notes
- **Research Notes** — map strategies and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Game Helpers
- Zone Timer — visualize shrinking play area
- Player Tracker — track nearby players in practice
- Replay Notes — record and review match runs
- Playback Speed — adjust replay playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Loot Catalog — browse weapons, attachments, gear
- Custom Skin Notes — organize player cosmetics
- Better Visibility — improved contrast for practice

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any map
- Gravity Flip Control — manually switch gravity mid-match
- Jump Buffer Notes — chain complex maneuvers in the editor
